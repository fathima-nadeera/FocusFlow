# FocusFlow ⏱️

A simple and modern Pomodoro productivity timer designed to help users stay focused, manage study sessions, and track their productivity.

## ✨ Features

- ⏱️ Pomodoro timer with Focus, Short Break, and Long Break modes
- ▶️ Start, Pause, and Reset controls
- 📝 Save current task using LocalStorage
- 📊 Track completed focus sessions
- ⏳ Track total focus time
- 🎯 Daily goal with progress bar
- 📜 Recent session history
- 📈 Weekly productivity chart
- 🔔 Completion notifications
- 🔊 Timer completion sound
- 🌙 Dark theme
- ☀️ Light theme
- 💾 Theme preference saved automatically
- 📱 Responsive design for mobile and desktop
- 🔴 Custom favicon

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Audio API
